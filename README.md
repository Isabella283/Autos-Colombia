Bienvenido al repositorio oficial del sistema de información para el parqueadero **Autos Colombia**. Este proyecto tiene como objetivo automatizar el control operativo de entradas, salidas, asignación de celdas y liquidación de servicios.

---

## 📌 Alcance de la Iteración 1

En esta primera iteración se aborda el módulo transaccional base para la gestión operativa en portería:
- Autenticación e inicio de sesión de operarios.
- Visualización en tiempo real del mapa/grilla de celdas (disponibles y ocupadas).
- Registro de entrada de vehículos con asignación automática/manual de celda.
- Registro de salida de vehículos y liberación de celdas.
